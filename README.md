# 隧雷智检 · 隧道结构三维数字孪生平台

基于 Web 的**隧道隐蔽病害三维数字孪生可视化平台**，是"隧雷智检——基于探地雷达的隧道隐蔽病害智能检测与分析系统"技术路线第 ⑤ 步"平台演示"的实现。

无需服务器、无需联网，浏览器打开即用。

---

## 快速开始

**在线访问（GitHub Pages）**：<https://llllllwwww.github.io/platform/>

**本地运行**：直接双击 `隧道三维数字孪生平台.html`（或 `index.html`），或在浏览器中打开该文件。

> `vendor/` 目录必须与本文件保持同级，请勿单独移动 HTML。

**支持环境**：Chrome / Edge / Firefox 等支持 WebGL 的现代浏览器（推荐 Chrome 或 Edge 最新版）。

## 功能概览

| 模块 | 内容 |
|---|---|
| **三维隧道模型** | 40 环盾构管片（980~1019 环，48 m）、双层钢筋网、壁后注浆层、五层地层模型 |
| **隐蔽病害可视化** | 16 处病害（空洞 / 富水 / 脱空 / 不密实 / 裂缝 / 钢筋异常），自发光 + 光晕 + 标注引线，透视衬砌可见 |
| **检测车第一视角** | 车载雷达视点自动遍历整条隧道，实时 B-scan 采集剖面、里程-环号联动、病害检出告警 |
| **多机械臂检测系统** | 平板车搭载 **3 台二连杆机械臂**（立柱门架 + 大臂 / 肘关节 / 小臂 / 腕部 GPR 天线阵），**由逆向运动学解算沿实测断面贴壁扫掠**（椭圆度 ±14 mm + 环缝错台 0~38 mm，贴合误差 0.000000 m），三臂分区互补；**第一视角下隐藏底盘、保留立柱与机械臂可见** |
| **随时暂停 / 继续** | 顶栏按钮或 **P** 键随时定格检测作业：车辆行进、机械臂扫查、天线脉冲、B-scan 扫描线一并冻结，便于讲解时定点细看 |
| **自由飞行漫游** | 键盘操控（WASD + QE + Shift）自由飞行，可飞入隧道内部或升到地表俯瞰（**G** 键切换） |
| **病害清单** | 左侧栏列出全部 16 处病害，点击行选中、点「定位」飞行聚焦，与等级筛选联动 |
| **结构健康评估** | 单体评分 → AHP+熵权组合赋权 → SHI 结构健康指数 → I~IV 风险分级 → 处治建议 |
| **多期次演化** | 5 期 SHI 时序曲线、劣化速率、风险指数、建议复检周期 |
| **交互分析** | 鼠标 360° 翻转、6 组视角预设、纵剖切面、等级/类型筛选、环向展开定位图 |
| **背景环境** | 程序化星空（900 点）+ 夜景城市天际线（亮窗纹理 / 楼顶障碍灯），可独立开关 |
| **报告导出** | 一键生成《隧道结构健康检测评估报告》初稿（UTF-8 文本） |

## 交互方式

| 操作 | 效果 |
|---|---|
| 左键拖动 | 360° 翻转隧道 |
| 滚轮 | 缩放（0.8 m ~ 160 m） |

| **空格** | 第一视角下暂停 / 恢复自动扫掠 |
| **Esc** | 退出第一视角 |

## 技术实现

- **渲染**：three.js r160（本地内置，非 CDN，保证比赛现场断网可用）
- **隧道几何**：参数化 BufferGeometry 生成管片环（外弧/内弧/两端环缝面），ShaderMaterial 实现衬砌透视
- **剖切**：three.js 局部裁剪平面，自定义 Shader 内联 `clipping_planes` 着色器块
- **相机控制**：自实现球面轨道控制（旋转 / 缩放 / 平移 / 触摸捏合），无外部依赖
- **第一视角**：相机锚定车体局部坐标，逐帧 B-scan 剖面整体重绘（解析伪随机，避免闪烁）
- **多机械臂**：车体分 `chassis`（底板/车架/车轮/驾驶台，第一视角隐藏）与 `arms`（立柱门架 + 机械臂组，第一视角保留）两层；机械臂经立柱门架与底板连成一体
- **贴壁运动学**：二连杆**逆向运动学**反解（`solveArmIK`），靶面为**随环号变化的实测断面**（`TunnelProfile`：椭圆度 + 环缝错台，48 档 LUT），运行时逐帧解算，臂端经一阶低通滤波跟踪；全环 × 全弧段 7320 点复核误差 0.000000 m
- **断面偏差**：`断面偏差可视化` 开关可叠加逐环彩色线圈（暖色=环缝错台，冷色=椭圆度压扁），与 HUD 的椭圆度/错台数值相互印证
- **暂停机制**：独立「作业时钟」`inspT`，暂停时冻结；车辆行进、机械臂扫掠、天线脉冲、B-scan 扫描线均由该时钟驱动，相机等观察类交互不受影响
- **评估模型**：单体评分 `score = 100×(1 − s_type·s_size·s_depth·s_pos)`，按项目计划书 5.6.2 分级判据导出等级
- **无构建步骤**：纯 HTML/CSS/JavaScript，单文件交付

## 数据说明

平台内的工点信息（地铁 4 号线 · 王家湾隧道）、里程（K3+128~K3+172）与 16 处病害台账均为**按项目计划书口径构造的演示数据**，尚未接入真实 `.dzt` 道集解译结果。

第一视角中的 B-scan 雷达剖面为**按病害台账参数程序化合成的示意剖面**（用于展示原始数据形态与双曲线特征），并非真实 `.dzt` 道集回放。

接入实测数据时，替换 HTML 中 `var DEFECTS = [` 数组即可，SHI、风险分级、图表、环向展开图与导出报告会自动联动。
