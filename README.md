# 隧雷智检 · 隧道智能检测与数字孪生运维平台

本地运行的中文工作台，依据《计划.docx》的四项内容组织为“检测采集、智能解析、孪生评估与运维、仿真推演”，并以项目总览串联业务。平台共用病害编号、检测批次、坐标、评估和处置记录，可演示从检测任务到报告导出的完整流程。

本版本包含实际可执行的 CSV 解析、数值预处理、AHP/熵权计算、参数化三维联动和本地处置记录。内置病害、示意雷达信号、健康评分配置与仿真预测均明确标记为演示；尚未连接真实识别模型或设备，不作为工程鉴定结论。

## 在线访问

**https://llllllwwww.github.io/platform/**

平台已通过 GitHub Pages 发布，浏览器直接打开即可使用，无需安装任何环境。建议使用支持 WebGL 的现代浏览器（Chrome / Edge / Firefox / Safari）。

## 启动

推荐在本目录双击 **启动平台.cmd**。启动器使用 Python 3 标准库，仅监听本机回环地址，并打开：

```text
http://127.0.0.1:8765/index.html
```

也可在本目录运行：

```powershell
python 启动平台.py
```

端口被占用时运行 `python 启动平台.py --port 8766`；无需自动打开浏览器时添加 `--no-browser`。终端按 `Ctrl+C` 停止服务。

前端无需构建、无需 npm 安装，不需要付费服务、API 密钥或联网接口。也可双击 `index.html` 使用文件模式，但浏览器对 `file://` 的本地存储与页面通信存在差异，推荐以上 HTTP 方式。请保留整个目录，不能只复制一个 HTML 文件；三维场景需要支持 WebGL 的浏览器。

## 四个业务模块

| 计划对应部分 | 页面 | 可以完成的操作 |
|---|---|---|
| 项目工作台 | `#overview` 项目总览 | 查看同源任务进度、病害、SHI、风险区段与预警，进入完整演示指引 |
| 1. 检测采集 | `#tasks` 检测任务与设备；`#radar` 雷达数据管理 | 新建任务、设定里程/速度/扫描范围、播放暂停与停障、导入 CSV、查看 B-scan 和单道波形 |
| 2. 智能解析 | `#processing` 智能处理工作流；`#defects` 病害清单与复核 | 执行真实减背景/时间增益、检查模型接口、病害筛选与复核；识别结果仍为内置演示台账 |
| 3. 孪生评估与运维 | `#twin` 三维数字孪生；`#health` 健康评估；`#alerts` 预警与治理；`#reports` 检测报告 | 三维定位、环位横断面、病害历史比较与 SHI 变化曲线、AHP/熵权与分级、预警闭环、治理任务、CSV/JSON/HTML/PDF 导出 |
| 4. 仿真推演 | `#simulation` 仿真验证工作台 | 雷达示意样本、检测车作业验证、简化圆环结构响应、运维方案比较四个页签 |

建议按总览的“完整演示流程”操作：检测任务 → 雷达数据 → 数值预处理 → 病害复核 → 三维定位 → 健康评估 → 预警处置 → 检测报告，再进入仿真工作台改变参数比较结果。

## 默认项目与数据边界

- 示范隧道长 **48 m**，里程 **K3+128—K3+176**，40 环、环号 980—1019，环宽 1.2 m，内半径 2.7 m，衬砌厚度 0.35 m。
- 最新批次为 `B202609`，历史批次为 `B202607`；16 条演示病害沿用原平台。历史直径与长度按当前值的 0.8 倍、面积按 0.64 倍派生，并非历史实测。
- 列表、三维与证据通过病害编号联动；复核按批次独立保存。CSV 导入的数据保持独立来源，**不会自动生成或覆盖病害台账**。
- 项目 JSON 导出按当前批次筛选任务、预警、日志、雷达目录与治理任务。全批次评估与当前筛选诊断分分别输出；没有批次归属的外部分析明确标记为项目全局参考。
- 所有业务状态保存在当前浏览器的 `localStorage`，不上传服务器。不同浏览器、端口及文件模式拥有独立存储。浏览器清理数据后记录可能丢失，应及时导出；项目 JSON 是结果快照，不是完整原始矩阵备份，也尚无一键导入恢复功能。

## 实现状态

| 类别 | 状态 |
|---|---|
| 可执行功能 | CSV 完整性检查；背景均值去除与线性时间增益；筛选、复核、批次隔离、三维联动；AHP/熵权/SHI；预警处置；文件导出与浏览器打印 |
| 演示计算 | 参数化隧道与三臂检测车；16 条病害和证据；历史派生；雷达纹理生成；几何停障/覆盖；均匀外压圆环响应；假设成本与降险方案排序 |
| 待接入 | RCAN、RTM、TunGPR/T-GPRMask 等候选模型，真实 GPR 原始格式适配器、硬件控制、经验证有限元模型 |
| 当前限制 | 无后台数据库/账号协同/云同步；无真实模型权重或电磁求解器；无工程鉴定效力；原始矩阵受浏览器存储容量约束 |

候选名称不等于已实现算法。“检查未接入模型”会明确返回失败；RTM 参数的参考稳定性校核不会产生偏移图像。前端展示的模型置信度不等同于诊断可靠性。

## 设计来源与对应关系

本次先阅读工作区《计划.docx》和《隧道智能检测与数字孪生平台_开发提示词.txt》，再分析 3 分 01.52 秒的模板演示视频。计划书实际为四项编号内容，因此设置四个一级业务模块，避免把所有功能堆在一个三维页面。

模板视频约 48～60 秒的原图/雷达与结果并列布局，被用于雷达管理和智能处理页；约 72～84 秒的三维、指标与环号查询关系，被用于孪生、病害清单和健康评估；约 96 秒的报告入口，被纳入可打印 HTML 报告中心。视频中的大语言模型知识问答未列入本次四部分计划，不在本版本中声称已实现。

新界面沿用深蓝工程底色，以绿色作为操作与选中状态，以红/橙/黄/绿表达风险；图表、清单与三维共用编号、里程、批次和评估版本。原有三维几何、检测车交互和背景资源融入新版工作台，各模块通过统一任务与病害数据联动。

## 录像三维重建与网格优化

新增独立模块 [algorithm/video_reconstruction](algorithm/video_reconstruction/README.md)，包含真实隧道录像抽帧、COLMAP 相机与稠密表面重建、裂缝候选分割、三维射线定位、规则断面拟合与补全，以及原始／优化表面对比页面模板。已记录 40 帧 DVP 公开视频的实际运行与验证结果。

该模块的代码和小型验证记录已入库；视频、模型权重、虚拟环境和大型重建产物由脚本在本地准备。它目前独立运行，尚未自动接入主工作台病害台账。环境、数据来源和完整命令见 [模块说明](algorithm/video_reconstruction/README.md)。

## 底层算法

平台的病害识别能力由 `algorithm/` 目录下的深度学习算法提供，与前端解耦：

| 环节 | 实现 |
|---|---|
| **数据** | 17338 张真实隧道衬砌现场照片（裂缝 / 渗漏 / 无病害）+ 带像素掩码的 TTD / CTCD |
| **标注策略** | 主线照片只有文件夹级标签 → 先用带掩码数据训练 AFPN-Seg 分割器，再伪标注生成检测框 |
| **模型** | YOLO11 + **AFPN**（Asymptotic Feature Pyramid Network，官方实现等价移植为纯 PyTorch） |
| **任务** | 检测 / 分割双头，类别：裂缝 crack、渗水 water、渗漏析出物 leaching |

数据全部由脚本一键下载（含来源链接与许可），训练验证全流程可复现：

```powershell
cd algorithm
python scripts\download_data.py                 # 下载数据（约 2.6 GB）
.\scripts\run_pipeline.ps1                      # 训练 + 验证 + 测试全流程
```

详见 [`algorithm/README.md`](algorithm/README.md)（环境、数据来源、切分防泄漏规则、模型接线）
与 [`algorithm/docs/REFERENCES.md`](algorithm/docs/REFERENCES.md)（RCAN / RTM / AFPN 对应论文与同类工作指标对照）。

> 前端顶栏标注的解译算法链 **RCAN + RTM + YOLOv7-AFPN**，当前已实现检测段（AFPN 颈部），
> RCAN 与 RTM 为后续阶段。

## 开发验证复现

日常运行不需要安装 npm 包。开发人员可运行 `npm test` 执行核心与适配器测试；如需复现浏览器验收，先安装开发依赖 `npm install`，运行本地启动器，再运行 `npm run test:browser`、`npm run test:retained` 和 `npm run test:entry`。测试默认使用 Windows 已安装的 Microsoft Edge；其他位置可通过环境变量 `BROWSER_EXECUTABLE` 指定。截图、下载验证及结果写入 `tests/output/`，该目录已被 Git 忽略。


## 原有功能融入新版模块

第一人称、启动/暂停、自由飞行、车载雷达 HUD、视角预设、自动旋转、剖切、图层和背景资源均直接在新版工作台使用。

| 所属模块 | 融入的功能与入口 |
|---|---|
| 检测采集 → 检测任务与设备 | 三臂检测车、第一人称视角、启动/暂停、车载 B-scan 与状态 HUD；任务进度和三维位置同步 |
| 智能解析 → 病害清单与复核 | 病害筛选、选中对象、详情与证据联动；雷达数据页提供 B-scan 和单道波形 |
| 孪生评估与运维 → 三维数字孪生 | 自由漫游、全屏、视角预设、自动旋转、剖切、病害定位与环位横断面、病害历史表、全批次 SHI 变化曲线、钢筋/注浆/地层/断面图层，以及星空、城市和本地背景图片 |
| 孪生评估与运维 → 评估、预警、报告 | 历史比较、统一 SHI、处置记录和导出；与三维和清单使用同一批次 |
| 仿真推演 → 作业验证 | 调整车速、间距与障碍物，计算结果可应用到检测任务场景 |

环位横断面和病害历史表跟随选中病害；全批次 SHI 曲线按两个示例批次、同一当前评估配置计算，显示分值变化及按实际批次间隔折算的单位时间变化率。曲线用于演示比较，不预测未来，也不表示实测劣化率。

在三维场景下方展开“场景工具、图层与背景”即可操作；更多按钮和快捷键见 [使用说明](平台使用说明.md) 的“原有功能在新版中的入口”。
