# 实验来源与验证范围

这份记录来自工作区中实际运行的 DVP 隧道录像实验，不是上传源码时重新训练或重跑的指标。

- 视频来源：https://commons.wikimedia.org/wiki/File:DVP_Tunnel_at_Moccasin_Trail_Park_in_Toronto_(20181008093109).webm
- 作者 / 许可：Sikander Iqbal / CC BY-SA 4.0。
- 视频 SHA-256：`0189d862b01ad628649a21b137f22cde5eb31bddba498298aad1960c589d0b9c`。
- 实测权重 SHA-256：`1797a21e11e811786bde88d6464c0030cca0493d9eeb741e4c436f15bd696f51`。
- 模型：外部 crack-seg U-Net + SE + 深监督，约 7.9M 参数。上游主分支与权重可能更新，应核对下载哈希，不能保证未来下载自动复现完全相同的结果。
- 实测环境：Python 3.11 / PyCOLMAP 3.13.0 负责 SfM，COLMAP 4.2 CUDA 负责稠密，PyTorch 2.9.1+cu128 负责推理与 GPU 求交。

规则化使用相机轨迹主轴、观测覆盖筛选、纵向三次 B 样条和周期 Fourier 断面，配合稳健重加权和二阶平滑约束。该实现适用于短、近直且断面可表示为星形轮廓的区段；不会为显著弯曲轨迹自动生成通用圆管。

优化网格只覆盖观测充分的隧道区段，原始网格还包含洞外地物。补全节点会记录局部点云支持情况，并可在前端着色。端盖是人工添加的闭合边界；封闭体每条边连接两个面，绕序一致向外。它不等于实际隧道入口处存在墙体。

缺陷关联要求：同一像素在原网格已有命中、位于拟合区段内，且新旧坐标移动不超过约 0.06397 相对单位。最终保留 432 个候选观测、26,838 个采样点。抽查 400 个点验证了图像回投、三角面内部性和坐标一致性。

这些检查证明代码接口、拓扑和输出自洽，没有证明病害准确率或毫米级定位精度。模型存在施工缝、涂写等误报；没有独立现场测量真值。
