# 隧道网格规则化与补全：实际结果

当前 [三维页面](web/index.html) 默认显示优化后的隧道，可切换“原始重建”保持同一相机视角对比，也可勾选“标出补全区域”“封闭端盖”。

![同一相机视角下的优化表面](results/browser_regularized/optimized.png)

## 为什么采用断面拟合

实际点云显示出稳定的拱顶、侧壁、平底和路缘轮廓；原网格却有碎片、孔洞和剧烈的局部法向变化。因此本次采用**点云约束的规则化重建**，而非仅在渲染时隐藏锯齿。

- 拉普拉斯 / Taubin 平滑适合已有拓扑较好的网格去噪，但不能独自解决大量孔洞与碎片；过度平滑还会收缩断面。
- Poisson 类重建可由带法向点云恢复连续表面，但需要控制未观测区的封闭与外推。
- 本次利用隧道的重复断面先验，直接用 **SciPy 三次 B 样条 + 周期 Fourier 断面 + 稳健拟合 + 结构化重网格化**。无需新增大型依赖，断面半径由实测点云估计。

## 已实现的处理过程

1. 从相机轨迹估计主轴与横断面坐标系，检查轨迹弯曲程度。这条短隧道适合近似直轴模型；显著弯曲的轨迹会被拒绝，后续需分段中心线版本。
2. 按纵向位置统计周向观测覆盖，提取连续的隧道区段，排除洞外道路和树木。当前有效区段沿恢复轴线约为 `[-1.5784, 6.1854] sfm_unit`。这是建模范围，前端两端开口不能一概认定为真实入口和出口。
3. 将观测分入 60 个纵向区间和 120 个周向区间，以中位半径降低异常点影响，并限制密集区域的权重，避免地面密集点压过墙面。
4. 使用 7 个纵向 B 样条控制系数组、12 阶周期 Fourier 基描述半径场 `r(s,θ)`。用 Huber 型迭代重加权拟合，并对纵向二阶差分与周向高频项加正则。断面允许非圆形，保留拱顶、侧墙和平底的大体轮廓。
5. 生成 180×192 的规则环形顶点网格。周向索引首尾连接，纵向连续；插值顶点法向提供平滑着色。另生成两个明确标记为人工添加的端盖，封闭体导出使用朝外的面绕序。
6. 由 COLMAP 使用同一批原始图像重新选择视图和贴图。优化内壁的全部 68,736 个三角面都找到了图像来源。
7. 对原始候选像素重新发射相机射线，只接受原网格已有命中、位于拟合区段内且位移不超过阈值的关联。原始坐标与被拒绝原因均保留。

实现：[regularize_tunnel.py](regularize_tunnel.py)、[relocalize_regularized.py](relocalize_regularized.py)、[前端打包模块](export_web.py)。核心现有依赖为 NumPy、[SciPy B 样条](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.BSpline.html)、SciPy 空间近邻与线性代数；GPU 射线求交复用已有 PyTorch 实现。

## 实测对比

| 指标 | 原始网格 | 规则化内壁 | 带端盖封闭体 |
|---|---:|---:|---:|
| 顶点数 | 191,529 | 34,560 | 34,562 |
| 三角面数 | 379,967 | 68,736 | 69,120 |
| 边界边 | 4,587 | 384，仅两端边界环 | 0 |
| 非流形边 | 0 | 0 | 0 |
| 连通部分 | 35 | 1 | 1 |
| 退化三角面 | 0 | 0 | 0 |
| 相邻面法向夹角 95 分位 | 57.22° | 3.40° | — |
| 三角形最长/最短边比 95 分位 | 4.04 | 2.03 | 2.03 |

原始网格包含洞外地物，优化网格限定于有效隧道区段，因此三角面减少同时包含裁剪和重网格化的贡献。法向比较仅使用相同纵向区段，并消除原网格绕序反向对夹角计算的影响。法向变化更小说明表面更平顺，不代表真实微小变形被更准确地恢复。

内部随机留出 1,160 个观测网格单元，半径拟合绝对误差中位数为 `0.00385 sfm_unit`，95 分位为 `0.03996 sfm_unit`。这是内部拟合检查，没有独立测量真值，不能转换成毫米精度。

## 补全与缺陷关联的边界

优化节点中有 **25,272 个**在原始点云的局部支持阈值内，**9,288 个**在阈值外。阈值约为 `0.03199 sfm_unit`；前端把后者及其邻近插值区域着成橙色，便于查看依赖几何先验较多的地方。这个近邻阈值是工程上的支持度判据，不是准确率。

- 优化表面接受 **432 个候选观测、26,838 个采样点**的关联。
- 每个接受点都保留同一图像像素在原始网格中的命中依据。
- 位移上限约 `0.06397 sfm_unit`；接受点位移中位数 `0.01133`，95 分位 `0.04695 sfm_unit`。
- 10,383 个采样像素缺少原始几何命中；6,399 个在拟合区段外；4,230 个位移过大；21 个没有命中新表面。它们没有被强行贴到规则化表面。
- 原始模式保留原有候选定位结果，规则化模式是用于展示的关联，不能宣称因此提升了病害坐标测量精度。裂缝模型仍可能把施工缝当成缺陷。

## 验证与导出

[几何检查](tests/verify_regularization.py) 已实际运行并通过：

- 内壁为单个连通曲面，只有两个边界环，均位于建模区段端点；没有内部孔洞边界。
- 封闭体每条边恰好邻接两个三角面，面绕序一致且向外，没有退化三角面。
- 纹理网格顶点与三角面索引和定位网格完全一致。
- 全部关联点通过原始依据和位移上限检查；抽查 400 个交点，验证相机投影、三角形内部性及平面残差。

[浏览器报告](results/browser_regularized/verification.json) 保存了实际 Edge 验证。原始/优化切换、补全着色、端盖开关、候选选择和时间切换通过；未出现 JavaScript 或 WebGL 错误。[几何报告](results/dvp_tunnel/regularization/verification.json) 保存精确指标。
